# GenZ Station QR Agent

Permanent station QR labels identify equipment but **do not authorize customer binding**. Each active station should display a short-lived QR generated by a trusted station-side process.

## Trust model

The agent is the trusted boundary. Its station-specific secret must never be placed in browser JavaScript, a customer QR, or a `NEXT_PUBLIC_*` variable. The agent requests a 60-second, single-use challenge from GenZ OS and displays the resulting customer URL locally.

Customer binding requires:

1. Customer OTP authentication.
2. A live challenge issued for that exact station.
3. An active session on that station.
4. Single-use, unexpired challenge validation inside a MySQL transaction.

## Configure the server

Set `GENZ_STATION_AGENT_SECRETS_JSON` on the GenZ server. Use a different random secret for every station and keep each value at least 32 characters, for example:

```text
GENZ_STATION_AGENT_SECRETS_JSON={"PC-01":"<32+ random characters>","PC-02":"<different 32+ random characters>"}
```

Do not commit the real secrets to Git.

## Run the trusted agent on a station PC

The repository includes `scripts/station-agent.mjs`.

Set these environment variables on the station PC:

```text
GENZ_SERVER_URL=http://<GENZ-ADMIN-PC>:3000
GENZ_STATION_ID=PC-01
GENZ_STATION_AGENT_SECRET=<the PC-01 secret>
GENZ_STATION_AGENT_PORT=17800
```

Then run:

```text
node scripts/station-agent.mjs
```

The agent binds its local display server to `127.0.0.1` only and opens the QR display in the station PC browser. The secret is sent only in the `x-genz-station-secret` request header to the GenZ server. The browser never receives the secret.

The display refreshes every 45 seconds while challenges expire after 60 seconds. A challenge is invalidated when a newer challenge is issued for the same station and is consumed atomically when the customer binds.

## Network/security requirements

- Keep MySQL inaccessible from the LAN; only the GenZ application should reach it.
- Allow the GenZ application port from the café LAN as required.
- Do not expose the station-agent port beyond `127.0.0.1`.
- Use HTTPS for `GENZ_SERVER_URL` when traffic can leave the trusted café LAN.
- Give every station its own secret so compromise of one station does not authorize another station.
